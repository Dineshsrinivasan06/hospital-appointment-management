# Hospital Appointment Management System

## Project Description

The Hospital Appointment Management System is a web-based application developed to simplify hospital appointment management.

The application provides an admin login system and a dashboard to manage doctors and patient appointments.

## Technologies Used

**Frontend:**
- React.js
- HTML
- CSS
- JavaScript

**Backend:**
- Python
- FastAPI
- SQLAlchemy
- JWT Authentication

**Database:**
- SQL database (as configured in the project)

## Main Features

- Admin registration and login
- Secure admin authentication using JWT
- Admin dashboard
- View doctors and appointments
- Search and filter appointments
- Edit appointments
- Cancel appointments
- Delete cancelled appointments
- Admin logout

## How to Run

1. Start the FastAPI backend.
2. Start the React frontend.
3. Open the application in your browser.
4. Login using the registered admin credentials.
5. Manage doctors and appointments through the dashboard.
